# SuperBattery ⚡

是一款专为硬件改装 Android 设备设计的电池电量与电压监测工具：适用于改装了 **标称 3.7V 锂离子电芯（满电 4.2V）** 并采用 **外部充电板与电池保护板（BMS）并联** 的设备，以此绕过系统默认的 3.85V/4.4V 锂聚合物电池管理电路。

---

## 📌 项目初衷与由来
_“我平时用一张 SIM 卡接打电话，另一张 SIM 卡用于移动数据上网。由于主力机仅支持双卡双待单通（DSDS），两张卡虽然同时待机，但同一时间只能有一张卡传输数据。只要我接听或拨打电话，移动数据就会断开——甚至在来电响铃的瞬间网络就会中断。为了解决这个问题，我改造了一部闲置旧手机：拆掉原装电池，保留原厂电池保护板（BMS），将手机 BMS、外置 3.7V 电芯以及外部充电板并联焊接，将其作为专用的 4G 转 Wi-Fi 随身热点。但随之而来一个难题：如何知道电池什么时候充满？由于电池完全通过外部电路充电，绕过了手机原生的充电控制芯片，Android 系统的电量显示会永远冻结在 1%。”_

* **基于电压的电池电量测算**：针对 3.7V 电芯放电曲线进行校准，通过原始毫伏（mV）读数真实反映剩余容量。
* **低电压系统通知**：在电池达到深度放电临界点前触发预警，防止电芯化学特性过早衰减。

_“作为一台专职的 4G 热点设备，仅仅显示原始电量还远远不够，还有哪些实用功能？”_
* **实时遥测图表**：记录并展示电压变化历史、电池温度以及系统可用 RAM。
* **主仪表盘界面**：集中展示实时曲线图、电池百分比以及网络数据流量。
* **自定义桌面小部件（Widget）**：直观显示电量百分比、温度、原始电压以及日期。
* **热点连接设备计数器**：直接嵌入在桌面小部件上，实时显示当前连接的客户端数量。
* **内置越南农历显示**：在小部件布局中集成公历与越南农历对照。

_“既然已经外接了大容量定制电芯，为什么不顺便把它当作应急移动电源使用呢？”_
* **反向充电功能**：可通过集成的移动电源充放电电路为其他外部设备供电。

## ⚙️ 技术说明与硬件特性

本应用严格围绕特定改装硬件的电气动态特性进行校准。在测试或移植到其他设备前，请注意以下设计约束：

* **电压放电查找表（Discharge Lookup Table）：**
  * 安全工作电压区间被映射在 **3550 mV (0%) 至 4140 mV (100%)** 之间。
  * 满电阈值刻意设定在 **4140 mV**（而非标准的 4200 mV），以补偿连接导线内阻以及外部移动电源充电管理芯片的截止特性。
  * 放电截止下限锚定在 **3550 mV**，既能防止锂离子电芯过放受损，也能避免 4G 射频模块高功率发射瞬间引起的瞬态压降导致手机意外重启。
* **热点客户端计数机制：**
  * 小部件通过**读取系统通知栏字符串**来识别当前已连接的设备数量，因此需要授予通知读取权限。
  * 目前尚未在其他定制系统（如 Samsung OneUI 或原生 AOSP）上进行兼容性测试。
* **温度预警阈值：**
  * 当监测到电池温度达到 **≥ 45°C (113°F)** 时，系统将触发紧急高温警告通知。
* **农历计算引擎：**
  * 固定基于 **GMT+7** 时区计算，并采用越南干支（Can Chi）纪年术语显示。
